# 交付与验证摘要

公开的能力范围见[需求基线](../REQUIREMENTS.md#当前实现能力)，部署和回退方法见[运行与部署](operations.md)。生产实例当前运行的版本、实际配置和原始验收证据由维护者在本地核对。

| 范围 | 验证内容 |
| --- | --- |
| 饮食记录 | 在隔离环境中检查新增一餐、修改指定食物份量和查询当天摄入。修改后核对回复、餐食合计和存储记录。 |
| 营养问答与菜单 | 检查回复是否使用查到的资料并附来源，菜单修改是否沿用已展示的方案。 |
| 部署与恢复 | 把待部署包、依赖 Layer 和实际运行版本对应起来，核对消息处理、账本归档及回退准备。离线或隔离验证通过的能力仍需对应的生产证据。 |

## 本地证据

原始对话、账本快照、日志、部署记录和生产配置保存在 Git 仓库外或已忽略的本地目录中。需要重放历史隔离验收时，向相应脚本传入本地基线报告、原始快照及菜单证据，具体参数见脚本的 `--help`。原始快照按报告中的 SHA-256 核对。

公共离线用例使用受控夹具。首次迁移专用的 CloudShell 脚本和配套检查与实际生产配置一起留本地，通用部署步骤继续维护在[运行与部署](operations.md)。
